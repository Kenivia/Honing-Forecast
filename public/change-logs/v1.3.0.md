# v1.3.0

This thing has been cooking for like 6 months and it's still lowkey not quite ready, but I wanted to get it out ~~before~~ on belgardin release.

## New features

### Screen scanner

Automatically input your owned mats AND CHESTS by sharing your screen.

You will not believe how complicated this thing is and I've only tested it on like 3 machines. There will for sure be issues, if you run into them, please do let me know.

Known limitations:

- Only full screen and borderless are supported.
- It may not work below 1080p.
- HDR and other brightness adjustments (or any kind of filter) will break it - unfortunately this means color blind mode does not work
- Non-default fonts may or may not work.
- Huge (bigger than 'largest') cursor sizes may break things.
- Only the English client is supported for now. It probably won't work with other languages.
- A lossless capture is required.
- T3 materials are not detected.
- Enhanced 19-20 books are detected as ordinary 19-20 books.

Couple things:

- It uses good old cpu based computer vision, nothing leaves your pc for processing.
- It uses 1 thread for the main cropping logic, and at most 3 threads for OCR([OCRS](https://github.com/robertknight/ocrs)).
- It uses datamined game files to establish what the icons look like & what chests are expected to contain. I used [Lost ark explorer](https://github.com/Poyoanon/lostark-explorer) to extract game files.

### Choices

The optimizer can now optimizer for how to open chests. This functionality can be extended to less obvious choices in the game. Currently only bonus boxes and paradise boxes are considered. All chests are evaluated by how much gold it saves you, so the value is very much specific to you, your owned mats, and your target upgrades.

No randomness in the chests are supported. Any kind of randomness would increase the amount of computation needed a LOT. As such, any choice like hell keys vs cube, or something like chaos brew are not supported.

 I will add cash shop in the future (the choice will be between turning it directly to gold or whatever package you buy.)

## Fixes & improvements

- various UI improvements
- added gold distribution graph, with pity / best case and their probabilities.

### Optimizer

- The optimizer's saddlepoint approximation evaluator has been swapped out for a slightly slower, more accurate and much simpler method.
- The optimizer itself has been upgraded to be faster, work better for when multiple materials are available (such as vambrace) and faster when it's starting from a similar state.
- The optimizer now default to using x10 streaks. If this is off, it is now no longer limited to 2 "streaks" and finds some better states as a result.
