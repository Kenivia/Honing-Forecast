# v1.3.4

## New features

- lostark.bible login
  - if you are logged in, all characters are automatically updated when you open the site (otherwise you need to press fech manually).
  - it also adds all your characters
- Added a dedicated info page
- Added option to forbid using certain chests on a character

## Fixes & improvements

- The scanner should now need less slots hovered if you have a previous scan
  - It assumes that you haven't swapped out an item for an identical looking but different (bound -> tradable for example) one, and no longer needs a hover in that case.
- Recognition of on-icon numbers is now done by glyph matching (with OCR fallback), which makes reading on-icon numbers  more reliable (This was needed since we now hover far less). This may cause custom fonts to work less well (You can upload your own font to help for this).
  - I don't even know if custom fonts affect this, I never tested thi
  - Tooltip reading is still done via OCRS
- Various UI improvements
- Updated guide and wrote an overview of how things work if you are interested.
- Updated the artisan formula to use integers like in-game.
  - The game files has a limit 21500, but I don't know if this is a >= or > (currently using >=). If you happen to know how to get this please let me know.
